# 基于 magpie 的体验优化

参考：[yetone/magpie](https://github.com/yetone/magpie)，2026-10-27 查阅的公开 README。采用其“添加提供商、搜索模型、接入客户端”和菜单栏快捷访问思路；实现沿用 ModelMoor 的 SwiftUI 界面、Application 会话入口和本地凭据存储。

## 已实现

| 流程 | 改进 | 验证方式 |
| --- | --- | --- |
| 添加端点 | OpenRouter、LM Studio 预设；现有预设默认地址；切换时保留自定义值；测试和保存期间禁止返回或取消；创建失败保持可见错误 | 预设 URL 测试、macOS 包编译 |
| 选择模型 | 多关键词搜索、仅看已选、选择当前结果、清空选择、刷新、已选模型跨刷新保留、手动模型、重复名称校验、保存进度与失败反馈 | 复用已有搜索测试、macOS 包编译 |
| 端点详情 | 发现模型可搜索；管理模型自动选中当前端点；未应用修改时禁用模型管理入口；状态头中的按钮独立可访问 | macOS 包编译及现有导航测试 |
| 统一 API | 按公开名、上游名和端点名搜索；复制模型名；移除确认；保存失败不提前移除界面中的模型 | macOS 包编译、现有持久化测试 |
| 客户端接入 | 按当前端口与公开模型生成环境变量及流式 cURL 示例；原生 Codex 使用 Responses；其他来源使用 Chat Completions；密钥通过环境变量传入 | JSON 往返、shell 转义、认证及协议分支测试 |
| 总览 | 更紧凑的标题与无卡片端点列表；统一 API、订阅、刷新快捷入口；空状态增加订阅入口；展示真实网关运行状态 | 就绪状态单元测试、macOS 包编译 |
| 菜单栏 | 有端点时仍可添加端点；增加订阅入口；模型数量与启用列表一致；网关失败不再显示启动中 | 就绪状态单元测试、macOS 包编译 |
| 一致性 | 总览、详情、菜单栏共用就绪状态规则；停用、检查中、缺凭据、无检测结果与非 2xx 状态不算就绪；新增文案提供简体中文翻译 | 状态优先级测试、本地化编译提取覆盖检查 |

## 有意保留的产品边界

ModelMoor 继续只监听 loopback，继续按公开模型名精确选择上游，不增加隐式重试、故障切换、公共网络监听或后台改写用户客户端配置。Ollama 原生预设用于模型发现；统一 API 接入应使用其 OpenAI 兼容 `/v1` 地址。

## 后续独立功能

| magpie 能力 | ModelMoor 的后续设计要求 |
| --- | --- |
| 客户端配置自动切换与 profiles | 客户端探测、格式保留写入、修改预览、备份恢复和并发修改检测；当前仅提供可复制配置 |
| 多账号故障切换与路由组 | 明确流式响应开始后的不可重试边界、计费语义、账号粘性和可解释的路由记录；当前仍精确路由 |
| 更完整的用量和额度信息 | 区分本机统计与供应商余额，明确可用 API、刷新策略与估算精度；当前保留现有用量与预算界面 |
| 请求隐私脱敏 | 单独设计工具调用、流式占位符还原、缓存一致性和误判处理；当前未添加脱敏功能 |

## 验证边界

自动化检查覆盖编译、状态、协议示例、现有导航与持久化回归和中文文案覆盖。真实供应商登录、真实推理请求、VoiceOver 朗读、浅色与深色模式以及不同屏幕尺寸仍需交互验收；编译通过不能代替这些验证。
